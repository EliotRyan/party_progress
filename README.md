# 入党积极分子电子档案

中国人民大学应用经济学院 · 本科第一党支部 — 入党流程查询与档案管理系统。

纯前端单页应用，数据存储在 `data.xlsx` 和 `admins.json` 中，支持通过 GitHub API 将修改推送回远程仓库。

---

## 快速开始

超级管理员将项目部署到 GitHub Pages 后，分享网址即可。学生和管理员均通过同一个网址访问，无需本地运行。

---

## 学生操作指南

学生无需登录，打开页面即可查询。

### 查询入党流程

1. 在查询区域输入**姓名**和**10 位学号**
2. 点击「查询」按钮（或按回车）

### 查看结果

查询成功后会展示以下内容：

| 区域 | 内容 |
|------|------|
| **书写规范横幅** | 材料书写基本要求 |
| **日期校验警告** | 如日期顺序有误，会显示 ⚠ 警告 |
| **入党流程时间线** | 6 个阶段节点：提交申请书 → 推优 → 积极分子 → 发展对象 → 预备党员 → 正式党员，每个节点显示对应日期 |
| **三模块卡片** | 📄 入党申请书页数、积极分子培训（院/校党校状态）、📄 考察登记表样表链接 |
| **材料清单** | 按四个阶段列出 21 项应备材料及完备状态（✅ 已完成 / 🔶 待完成 / ⬜ 未到） |
| **阶段注意事项** | 根据当前入党阶段给出具体书写规范和流程提示 |
| **思想汇报与培养考察表** | 自动推算每季度截止时间及到期状态（已到期 / 即将到期 / 未到） |
| **联系人信息** | 自动匹配所在支部党务联系人的邮箱 |

## 管理员操作指南

点击页面右上角「管理」按钮，输入学号和密码登录。

### 角色与权限

| 角色 | 可管理档案范围 | 可管理 GitHub 配置 | 可管理其他管理员 |
|------|---------------|-------------------|-----------------|
| `super` 超级管理员 | 全部学生 | ✅ 配置 + 生成分享码 | ✅ |
| `secretary` 党支部书记 | 全部学生 | ❌ 仅可导入分享码 | ❌ |
| `contact` 党务联系人 | 所在支部学生 | ❌ 仅可导入分享码 | ❌ |

- `secretary` 和 `contact` 在档案管理工具栏会看到「📥 导入配置」按钮，用于从超级管理员获取分享码来配置 GitHub 同步。

### 档案管理

标签页「档案管理」提供：

| 操作 | 方法 |
|------|------|
| **搜索** | 在搜索框输入姓名或学号 |
| **筛选** | 通过「全部支部」下拉筛选支部，通过「全部阶段」下拉筛选入党阶段 |
| **排序** | 点击表头列名可按该列升序/降序排列 |
| **新增** | 点击「➕ 新增」按钮，在弹出的表单中填写信息（所在支部为下拉选择，不可自定义） |
| **编辑** | 点击行末「编辑」按钮，修改后保存 |
| **删除** | 点击行末「删除」按钮，确认后删除 |
| **批量修改** | 勾选多行后，通过底部工具栏选择字段和新值，点击「应用」 |
| **批量删除** | 勾选多行后，点击「批量删除」 |
| **导出** | 点击「📥 导出」下载当前档案为 `.xlsx` 文件 |
| **保存** | 点击「💾 保存」将数据推送到 GitHub 仓库 |

### 数据导入

标签页「数据导入」：

1. 选择「追加导入」（保留已有数据）或「完全覆盖」（仅 `super` 可用）
2. 拖拽或点击上传 `.xlsx` 文件
3. 系统会显示导入结果

### GitHub 配置（仅 `super`）

1. 在「GitHub 配置」标签填写 **用户名**、**仓库名**、**Token**（需有仓库写权限）
2. 点击「保存」
3. 点击「📤 生成分享码」可将配置导出为字符串，复制给其他管理员

### 导入分享码（`secretary` / `contact`）

1. 在档案管理工具栏点击「📥 导入配置」
2. 在「导入分享码」区域粘贴超级管理员提供的分享码
3. 点击「📥 导入」

### 修改密码

1. 标签页「修改密码」
2. 输入当前密码、新密码、确认密码
3. 点击「修改」，更改通过 GitHub API 写入 `admins.json`

### 管理员管理（仅 `super`）

标签页「管理员管理」：

- **添加**：填写学号、姓名，选择角色（党支部书记 / 党务联系人），管辖支部（联系人需指定，其他角色默认全部学生）
- **重置密码**：重置指定管理员的登录密码
- **删除**：移除管理员

## 数据文件

### `data.xlsx`

| 字段 | 类型 | 说明 |
|------|------|------|
| 姓名 | 文本 | 学生姓名 |
| 学号 | 文本 | 10 位学号 |
| 所在支部 | 下拉（不可自定义） | 如 `2025级1班`、`2025级数科班`，范围 2020—2030 级 + `2025级0班`（范例） |
| 入党申请书日期 | 日期 | |
| 入党申请书页数 | 文本 | 如 `5` |
| 团支部推优日期 | 日期 | |
| 确定积极分子日期 | 日期 | |
| 确定发展对象日期 | 日期 | |
| 预备党员日期 | 日期 | |
| 正式党员日期 | 日期 | |
| 院党校培训 | 下拉（是/空） | |
| 校党校培训 | 下拉（是/空） | |

入党阶段由日期字段自动判定，优先级从高到低：正式党员 → 预备党员 → 发展对象 → 积极分子 → 推优 → 已提交申请 → 未提交。

### `admins.json`

```json
[
  {
    "id": "学号",
    "name": "姓名",
    "role": "super | secretary | contact",
    "scope": "全部学生 | 具体支部名称",
    "pwdHash": "SHA-256 哈希值"
  }
]
```

## 技术栈

- 纯 HTML/CSS/JS，零框架依赖
- [SheetJS (xlsx)](https://sheetjs.com/) 处理 Excel 读写
- SHA-256 密码哈希（Web Crypto API）
- GitHub Contents API 实现数据持久化
- Noto Serif SC / Noto Sans SC 字体
- 毛玻璃效果（backdrop-filter）
